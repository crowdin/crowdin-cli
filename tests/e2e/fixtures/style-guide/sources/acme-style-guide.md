# Acme App Localization Style Guide

## Tone and voice

- Friendly and concise. Address the user directly (informal "you").
- Avoid slang, idioms and humor that do not translate well.

## Terminology

- Keep product names untranslated: Acme, Acme Cloud, Acme Sync.
- "Sign in" / "Sign out", never "Log in" / "Log out".

## Formatting

- Preserve placeholders exactly: {count}, %s, {{name}}.
- Keep HTML tags and their order; translate only visible text.
